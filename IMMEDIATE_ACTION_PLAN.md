# ⚡ Immediate Action Plan - Wallet Names

## 🎯 The Quick Fix (5 Minutes)

Follow these steps to see your wallet names on transactions:

### Step 1: Open Wallet Settings
1. Open **Sat Sorter**
2. Click **"Import Transactions"** button
3. Go to **"Alby Hub"** tab
4. You'll see your connected wallets

### Step 2: For Each Wallet - Delete & Re-add

**For Wallet 1 (e.g., Alby Hub):**
```
1. Find "NWC Wallet" or unnamed wallet in the list
2. Click the trash/delete icon (doesn't delete transactions)
3. In "Add Another Wallet:" section:
   - Wallet Name: "Alby Hub"
   - NWC URI: [paste your connection string]
   - Click "Connect"
4. Click the sync button (↻) next to it
```

**For Wallet 2 (e.g., Mutiny):**
```
1. Delete the old unnamed connection
2. In "Add Another Wallet:" section:
   - Wallet Name: "Mutiny"
   - NWC URI: [paste your Mutiny connection string]
   - Click "Connect"
3. Click the sync button (↻) next to it
```

**For Wallet 3 (e.g., Zeus):**
```
1. Delete the old unnamed connection
2. In "Add Another Wallet:" section:
   - Wallet Name: "Zeus"
   - NWC URI: [paste your Zeus connection string]
   - Click "Connect"
3. Click the sync button (↻) next to it
```

### Step 3: Refresh & View

1. **Refresh the page** (or wait a few seconds)
2. **Go to Transactions** panel
3. **See wallet names!** 🎉

```
Expected result:
☕ Coffee
🟦 Alby Hub | -5,000 sats  ← Shows actual wallet name!

💰 Salary
🟦 Mutiny | +500,000 sats  ← Clear identification!

⚡ Fee
🟦 Zeus | -3,500 sats      ← No more confusion!
```

## 📋 Wallet Name Ideas

**Use clear, descriptive names:**

```
✅ Good Examples:
- "Alby Hub (Main)"
- "Mutiny (Mobile)"
- "Zeus (Self-Hosted)"
- "Alby Hub - Income"
- "Mutiny - Daily Spend"

❌ Avoid:
- "Wallet 1"
- "NWC"
- "test"
- "wallet"
```

## ✅ What Changed

| Before | After |
|--------|-------|
| "🟦 Lightning" | "🟦 Alby Hub" |
| Can't tell wallets apart | Crystal clear which wallet |
| Wallet name optional | Wallet name required |
| Generic fallback | Specific wallet identification |

After these simple steps, all your transactions will show the correct wallet name.
