## 🚀 To Get Started

1. **Name your wallets clearly**
   ```
   ✅ "Alby Hub (Main)"
   ✅ "Mutiny (Mobile)"
   ✅ "Zeus (Self-Hosted)"
   ❌ Don't use: "Wallet 1", "test", "NWC"
   ```

2. **Connect them via NWC**
   - Import → Add NWC Connection
   - Paste connection string
   - Give it the clear name above

3. **Enable auto-sync**
   - Transactions sync every 5 minutes
   - Each shows the wallet name

4. **See wallet names on transactions**
   - Look at Transactions panel
   - See badge with wallet name
   - Click for full details

## ❓ FAQ

**Q: What if I only have one wallet?**
A: Wallet name still shows! Makes it clear which wallet to check if issues arise.

**Q: Can I change wallet names later?**
A: Yes! Edit the wallet connection. New transactions use the new name.

**Q: Will old transactions show the wallet name?**
A: Only if imported after this update. Older ones fall back to "Lightning".

**Q: Does this work on mobile?**
A: Yes! Same wallet names on all devices via cloud sync.

**Q: What colors do wallet badges have?**
A: Blue (🟦) for Lightning wallets. Stays consistent across all views.
